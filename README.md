# libfijurextract

The MFCC (Mel-Frequency Cepstral Coefficients) audio feature extraction library is written in pure C99, does not depend on external libraries and is not dynamically allocated (malloc/free). The entire working memory is managed through a user-provided static memory area, enabling consistent implementation across both PCs and microcontrollers.

Documentation is available in [docs.md](docs.md).
